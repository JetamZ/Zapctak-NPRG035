### Short Description
The aim of the project was to create a console application, that would
be able to load an image and convert it into <a href="https://en.wikipedia.org/wiki/ASCII_art">ASCII art</a>.
Additionaly, the user is provided with means to configure the Ascii art
generation using many different parameters (for more information, see user documentation).
Program is also capable of real time ASCII art generation from camera of the device, however,
there are some assumptions.
**Main ideas**
- The program loads image into it's working memory and replaces pixels (or groups of pixels)
with symbols whose brightness is closest to that of the pixel (group of pixels).
- Brightness of symbols is cumputed as follows:
    ```
    Input: Singular symbol
    Output: Birghtness - average brightness of pixel in 50x50 bitmap containing the symbol
    ----------------------------------------------------------------------------------
    1. Create a 50x50 bitmap
    2. Draw the symbol  onto it
    3. Get average brightness of pixel
    4. Return the average brightness of pixel
    ```
    Symbol is drawn on a white background using black color.
- When it comes to the brightness of pixels, there are two possible approaches user can pick from:
    - **1. Human Eye** - Takes the RGB components of the pixel  and performs a weighted
    sum with weights corresponding to sensitivity of human eye to red, green and blue color.
    - **2. RGBA** - Takes the most significant component of RGB and returns it as brightness.
- Then appropriate symbol is selected from list of symbols that can be used and is appended to 
resulting string that will eventually hold the entrie ASCII art.
- The **Real time Camera Mode** displays the 'ASCII video' in `Spectre.Console.AnsiConsole`
- Size of the rame can be configured by user, but there may be need to zoom out the
  console for the ascii video to be displayed smoothly.
### User Documentation
- In this section, I will provide the information regarding running application and configuring it.
#### Configuration
- Configuration is done via configuration file (e.g.`configuration.txt`).
- This file may be saved wherever you wish, but when running the application, you'll
need to provvide path to it as a command-line argument.
- **Structure of configuration file:**
    - Example :
        ```
        Real Time:F
        Brightnes Calculation:2
        Symbols:Auto;35
        Reversed:F
        Scale:FAST
        Width:180
        Height:120
        ```
    - Each line of the configuration file has the form of `parameter:value`.
    - **Individual parameters:**
        - **`Real Time`**
            - Possible values are `T` (true) or `F` (false), if `T` then application starts in the real-time
            mode and displays 'ASCII video'
            - The application takes image from built-in camera (e.g. on laptop), I didn't have a chance
            to test it on classic desktop computer, but from the documentation of OpenCVsharp,
            it should work as well (if there are multiple attached cameras, the firt one is selected).
        - **`Brightness Calculation`**
            - Approach to calculating the brightness of pixels / groups of pixels.
            - Possible options here are `1` (human eye approach) and `2` (brightest RGB component approach).
        - **`Symbols`**
            - What symbols are to be used in the ASCII art.
            - There are two possibilities here:
                - **1.`Auto;<number>`** - The list of characters is generated by the application 
                and `<number>` of them is actually used in the symbol pool.
                The effects of `<number>` are with rising `<number>` the 'saturation'
                of resulting ASCII art is increasing.
                - **2.`<string>`** - A singular string containing all the symbols to be used.
                In this case, all of them are included in the final symbol pool.
        - **`Reversed`**
            - Possible values are `T` (true) of `F` (false)
        - **`Scale`**
            - Possible options here are: `DEFAULT`, `FAST`, `SMOOTH`
            - Describes how the new pixel value is to be calculated when scaling the image
            - General rule is from left to right quality increases and speed decreases.
        - **`Width`**
            - Any number, it is the width of the resulting ASCII art.
        - **`Height`**
            - Any number, it is the height of the resulting ASCII art.
### Running the application
#### Getting the application
- To successfully get the application from Git follow these steps:
    - **1.** Navigate to the folder you would like to download the application to.
    - **2.** Open Console in that folder.
    - **3.** Execute `git clone https://github.com/JetamZ/Zapctak-NPRG045.git`
    - **4.** Navigate to the cloned repo.
    - **5.** Get nugget packages: `dotnet restore`
    - **6.** Build the application: `dontnet build`
    - **7.** Navigate to the `BacomZapoctak`
    - **8.** Run the application `dotnet run`
- **Note 1**: The above steps assume you have git and dotnet SDK installed, if not and you wish to get the application from git, please install them
- **Note 2**: The other option is to open the `AsciiArtGenerator.sln` in Visual Studio and continue from there. If you do that, and you wish to work with example images / configurations I provided, please set the working directory to `BacomZapoctak/`
#### Running options
- There are three options how to run the application.
- **Option 1** - If you wish to run it in real-time mode run the application with single
                 command line argument: `<path_to_configuration>`
- **Option 2** - If you wish to convert a single image into ASCII art, run the application with 3 command-line arguments
    - **1.** `<path_to_configuration>`
    - **2.** `<path_to_input_image>`
    - **3.** `<path_to_output_txt_file>`
- **Option 3** - If you do not have configuration files ready, you may run the application with no command
line arguments. That will allow you to configure the program when it is ran. The application will ask you questions
and provide you with configuration options, from which you can choose from.
    - **Note:** If you chose, the non-realtime mode here the appication will also ask you for the path to the source image and the destination you want to save the ascii art to. If no destination is specified, the result is printed on standard output.


### Programming Documentation
- The entire appilcation is divided into multiple projects / modules based on what belongs together.
- This section is going to describe the individual modules and their components.
- The modules are : **`AsciiArtGeneration`**, **`BrightnessCalculation`**, **`ColorRepresentation`**, 
**`ImageRepresentation`**, **`RealTimeCamera`**, **`SymbolRepresentation`** and a module containing
entrypoint and related functionality: **`BacomZapoctak`**
#### `AsciiArtGeneration`
- This module groups the main functionality of application.
- Contains classes that tie together functionality of other modules into a final Ascii art generator.
- The classes are **`AsciiArtGenerator`**, **`AsciiConverter`**, **`GeneratorConfig`**
- **`AsciiArtGenerator`**
    - This class has two overloads for the same method `generate()` and one private utility method 
    `getSymbol()`
    - First overload is `generate(string imagePath, GeneratorConfig configuration)`
        - This method attempts to load the image from specified path, construct an image
          wrapper (discussed later) and pass it along with configuration to the second overload, which
          then generates the final string.
    - Second overload is `generate(ImageWrapper image, GeneratorConfig config)`
        - This method applies the symbol transformation to each pixel of the image.
        - Symbol transformation means: 
            - *1.* Get pixel's color and determine brightness
            - *2.* Get appropriate symbol
            - *3.* Append the symbol to final string
            - *4.* If the pixel was right border pixel, add a `\n` too.
        - Above process is repeated for each pixel, and after that the resulting string is returned.
    - `getSymbol(int brightness, int symbolGap, string[] symbols)`
        - This method returns the appropriate symbol from provided symbol pool according to 
        brightness and symbol gap.
        - `birghtness` is the brightness of pixel, that is to be replaced.
        - `symbolGap` is the amount of brightness values one symbol covers (for reasonable indexing into the symbol pool).
- **`AsciiConverter`**
    - This class contains mainly the functionality for parsing the configuration file.
    - It has one static field `GeneratorConfig configuration` into which the config file is being parsed.
    - **`public static readConfiguration(string filePath)`**
        - Takes path to the configuration file as argument.
        - Reads and parses the configuration file contents into the configuration field,
        then returns it.
    - **`private static string[] getUTFChars(int start, int finish)`**
        - Private utility method for getting UTF characters within specified range.
        - `int start` - start of the range.
        - `int finish` - end of the range.
- **`GeneratorConfig`**
    - Class for representing the configuration of ASCII generator.
    - **Properties**:
        - `PixelScale scale` - holds information about pixel scale (see `ImageRepresentation`)
        - `string[] symbols` - symbol pool
        - `IBrightnessCalculator brightnessCalculator` - algorithm to use for pixel brightness 
        calculation
        - `bool isReversedSymbol` - Flag for flipping the brightness values (big value bright vs big value 
        dark)
        - `bool realTime` - Flag for toggling the real-time mode.
    - **Methods**:
        - `public string[] getSymbols()`
            - returns the symbol pool
            - takes into account the `isReversedSymbol` flag, if set, returns the symbol pool reversed.
        - `private string[] reverseArray(string[] array)`
            - utility method
            - reverses the `array` and returns it
        - `public override string ToString()`
            - Override of the `Object.ToString()` method for converitng the configuration object into a `string` form suitable for serialization into configuration `.txt` files.
#### `BrightnessCalculation`
- This module groups functionality related to computing the brightness of pixel(s).
- **`IBrightnessCalculator`**
    - nterface for all brightness calculation algorithms.
    - enforces implementation of `public int getPixelRepresentation(int red, int green, int blue)`
    method
    - All algorithms for computing brightness of pixels from image are required to implement this
    interface to be possible to use.
- **`HumanEyeAlgorithm`**
    - Brightness calculation algorithm
    - Implements `IBrightnessCalculator`
    - **Methods**
        - `public int getPixelRepresentation(int red, int green, int blue)`
            - Computes the brightness from given colors as a weighted sum.
            - The weights used are constants that correspond to real life human eye
            sensitivity to red, green and blue color. 
- **`RGBAlgorithm`**
    - Brightness calculation algorithm
    - Implements `IBrightnessCalculator`
    - **Methods**
        - `public int getPixelRepreseentation(int red, int green, int blue)`
            - Computes the brightness by getting the most significant RGB component.
#### `ColorRepresentation`
- This module groups the functionality related to representation of colors within the application.
- **`ModifiableColor`**
    - public abstract class, from which all colors should inherit.
    - **Fields**
        - `public int colorValue` - significance of the color assumed range 0 - 255.
    - **Methods**
        - `private void checkAndNormalizeColor()`
            - Checks whether the colorValue fits within the range 0-255, if not, clamps it into that 
            range.
        - `public void Add(toAdd)`
            - Allows for adding to colorValue.
            - After addition calls `checkAndNormalizeColor()`
        - `public void Substract(toSubstract)`
            - Allows for substracting from colorValue.
            - After addition calls `checkAndNormalizeColor()`
        - `public void Multiply(multiplyBy)`
            - Allows for multiplication of colorValue.
            - After addition calls `checkAndNormalizeColor()`
        - `public void Divide(divideBy)`
            - Allows for division of colorValue.
            - After addition calls `checkAndNormalizeColor()`
        - `public override string ToString()`
            - Override for conversion to string.
- **`Red`**
    - Class representing red component of the RGB triplet.
    - Inherits from `ModifiableColor`
- **`Green`**
    - Class representing green component of the RGB triplet.
    - Inherits from `ModifiableColor`
- **`Blue`**
    - Class representign the blue component of the RGB triplet.
    - Inherits from `ModifiableColor`
- **`PixelColor`**
    - Class for representing the color of a pixel as the RGB triplet.
    - Holds the color itself as openCVsharp's `Vec3b` structure as well as individual components fo the color. 
#### `SymbolRepresentation`
- Groups together fuctionality revolving around representing and working with symbols.
- **`Symbol`**
    - A class that holds the symbol itself, aloong with the calculated symbol brightness.
    - **Properties**
        - `symbol` - character itself.
        - `brightness` - decimal, brightness of the symbol.
- **`SymbolList`**
    - A class representing the symbol pool that is to be used in the ascii art.
    - Holds the the array of symbols used and attempts to keep it sorted based on 
    symbol's birghtness values.
    - **Properties**
        - `sortedSymbols` - Array holding instances of `Symbol`.
    - **Fields**
        - `acceptableSymbolAccuracy` - How many brightness values are represented by one symbol.
    - **Methods**
        - `AddSymbol(Symbol toAdd)`
            - Method for adding new symbol to the symbol list.
            - Takes the symbol and calculates appropriate index to the array of symbols based on it's brightness.
            - Then if the place at that index is free, meaning no symbol has been assigned to this index yet, it stores it to that index.
            - If there already is a symbol at target index, it compares the new symbol to exiting one,
            if the new symbol fits better, it is replaced by a new one, else, the former is kept.
        - `size()`
            - Counts the occupied slots within the symbol list.
        - `getSymbolsAsString()`
            - private method used by overriden `ToString()` method.
            - For debugging purposes.
- **`BestSymbolPatternFinder`**
    - Basically a `SymbolList` builder.
    - Takes in array of symbols and finds best ones for the ascii art among them.
    - **Methods**
        - `static SymbolList findBestPattern()`
            - There are 3 overloads of this method `findBestPattern(param string[] symbols)`,
            `findBestPattern(int maxSymbols, param string[] symbols)`
            and `findBestPattern(int symbolAccuracy, int maxSymbols, param string[] symbols)`
            - The first one calls the second one with maxSymbols being 255.
            - The second one calls the thrid one with symbolAccuracy 10.
            - The third one then finally constructs the SymbolList itself, from `symbols` with respect to the `symbolAccuracy` and `maxSymbols`.
        - `static decimal getCharacterBrightness(string character)`
            - This method is responsible for determining the brightness of a character.
            - It is done by averaging the brightness of a pixel from 50x50 bitmap with white background and that
            character drawn using the `Consolas` font.

#### `ImageRepresentation`
- This module groups everything needed for internal representation of an image.
- **`ImageWrapper`**
    - Class that sort of wraps the image with some useful functionality.
    - Holds picture represented as `PixelGroup` instance.
    - Can be constructed directly using path to the target image or wrap around `Mat` instance.
    - **Properties**
        - `public PixelGroup pixels` - Pixels of the image represented utilizing `PixelGroup` class discussed later.
        - `public int width` - Width of the currently held image.
        - `public int height` - Height of the currently held image.
    - **Methods**
        - `public ImageWrapper getScaledVersion(PixelScale scale)`
            - This method is responsible for resizing and scaling the image according
            to provided scale.
            - Uses the `Cv2.Resize` method.
        - `public bool isBorderPixel(int x, int y)`
            - Determine whether a pixel is on border of the image based on it's
            x and y cooridnate.
        - `public bool isHorizontalBorderPixel(int x)`
            - Determine whether a pixel is on horizontal border.
        - `public bool isVerticalBorderPixel(int y)`
            - Determine whether a pixel is on vertical border.
- **`PixelGroup`**
    - Class for holding all the individual pixels (instances of `SingularPixel`) of an image, so that they can 
    be iterated over and manipulated.
    - Holds the internal picture represented as `OpenCvSharp.Mat` instance.
    - Implements the `IEnumerable<SingularPixel>` interface which is done with the aim to
    allow enumeration over pixels as instances of `SingularPixel` class.
    - **Properties**
        - `public Mat internalImage` - The source image itself as an instance of `OpenCvSharp.Mat`.
        - `public int Width` - Width of the `internalImage`
        - `public int Height` - Height of the `internalImage`
        - `public int size` - `Width` x `Height`
    - **Methods**
        - `public void applyToAllPixels(Action<SingularPixel> action)`
            - Method to apply specified function to all pixels.
            - Used to select appropriate symbol for each pixel in `AsciiGeneration.AsciiGenerator.generate()` method discussed above.
        - `public IEnumerator<SingularPixel> GetEnumerator()`
            - Method yielding each pixel as `SingularPixel` instance.
            - Used to get `IEnumerator<SingularPixel>` for `IEnumerator IEnumerable.GetEnumerator()` method.
        - `IEnumerator IEnumerable.GetEnumerator()` 
            - Method enforced by the `IEnumerable contract`.
- **`Scale`**
    - Enum holding scaling options as flags.
- **`InterpolationMappings`**
    - Class for mapping the `Scale` to the `OpenCvSharp.InterpolationFlags`
    - **Methods**
        - `public static OpenCvSharp.InterpolationFlags ToOpenCvFlag(Scale scale)`
            - Method that returns appropriate interpolation flag for provided scale option.
- **`PixelScale`**
    - Class holding the picture scaling configuration.
    - **Properties**
        - `public int width` - Desired width after scaling.
        - `public int height` - Desired height after scaling.
        - `public Scale scale` - Desired scaling option.
- **`SingularPixel`**
    - Class for representing a singular pixel.
    - **Properties**
        - `public int x` - X coordinate of the pixel within image.
        - `public int y` - Y coordinate of the pixel within image.
        - `public PixelColor color` - Color of the pixel represented as instance of `ColorRepresentation.PixelColor` class.
#### `RealTimeCamera`
- Module implementing real-time functionality.
- **`RealTime`**
    - **Methods**
        - `private static ImageWrapper? getCameraImage(VideoCapture camera, int widht, int height)`
            - Method taht fetches an image from camera and if succeeds returns the image
            wrapped in `ImageReperesentation.ImageWrapper`.
        - `public static void work(GeneratorConfig configuration)`
            - Main loop of the real-time mode.
            - Attempts to accsess the camera.
            - If succeeds then initializes and starts `Spectre.Console.AnsiConsole` in a live mode.
            - Until the application is terminated, image is fetched from the camera,
            converted to ASCII art and displayed.
            - This process is repeated every 50 miliseconds.
#### `BacomZapoctak`
- This module serves as entry point to the application.
- **`InteractiveConfigBuilder`**
    - Class handling the interactive configuration of application, if the path to tohe configuration file is not specified.
    - Asks user about the desired parameters of the run.
    - Is capable of storing the configuration user created in interactive mode.
    - **Methods**
        - `public static GeneratorConfig makeConfiguration()`
            - Interactively builds the `AsciiArtGeneration.GeneratorConfig` by asking
            user to fill in individual fields.
            - Calls later described private methods (for each config section) and then
            asks the user wheteher they wish to store the configuration they have built and if so, where.
            - **returns** built `GeneratorConfig` object.
        - `private static bool askRealTime()`
            - Asks user about the real-time configuration field.
            - **returns** either `true` (if user entered `Y`) or `false` if user entered `n`.
        - `private static IBrightnessCalculator askBrightnessCalculator()`
            - Provides user with brightness calculation options and asks them which one
            they would like to use.
            - **returns** desired brightness calculation algorithm.
        - `private static string[] askSymbols()`
            - Asks user wwhat symbols they wish to use.
            - If user enters `auto` generates symbols automatically calling the `AsciiConverter.getUTFChars(32, 162)` and asks user
            how many of these automatically generated symbols they wish to use,
            then **returns** symbols as result of
            `BestSymbolPatternFinder.findBestPattern(4, <user_number>, <automatic_characters>)`.
            - If user entered a list of desired symbols as a `string`, separates each character of that string and **returns** it as `string[]`
        - `private static Scale askScale()`
            - Offers user the choice of scaling options (`ImageRepresentation.Scale`)
            and asks them to choose one.
            - **returns** `ImageRepresentation.Scale` based on user's choice.
        - `private static bool askReversed()`
            - Asks user whether they wish to reverse the meaning of 'brightness'
            - **returns** `true` if user entered `Y` esle `false`
        - `private static int askWidth()`
            - Asks user about the width of resulting Ascii Art (in characters).
            - Defaults to `200`            
            - **returns** The number user has entered.
        - `private static int askHeight()`
            - Same as `askWidth()` but for height.
            - Defaults to `100`
        - `private static void askStore(GeneratorConfig config)`
            - Asks user if they wish to store the configuration they built.
            - If yes, allows them to specify location or use the default, which is
            `<path_to_zapoctak_root>/BacomZapoctak/bin/Debug/net9.0/config/CustomConfig.txt`
    - **`Program`**
        - Entry point class of the entire application.
        - Switches into different modes of running based on provided command line arguments.
        - If no arguments were provided, runs in interactive mode utilizing `InteractiveConfigBuilder's` functionality to build configuration during runtime.
        - If there are two command-line arguments (`configuration file` and `image source file`) the Ascii Art is printed on standard output.
        - If there are three command-line arguments (`configuration file`, `image source file` and `ascii target file`) the resulting Ascii art is written into `ascii target file`
        - For more information on command line arguments, please revisit the ***Running the application section***.
        - **Methods**
            - `public static void Main(string[] args)`
                - Entry point, decides how to run based on command-line arguments.
            - `private static void runInteractive()`
                - Handles running in the interactive configuration building mode.
